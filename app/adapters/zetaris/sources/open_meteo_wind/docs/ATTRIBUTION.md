# Open-Meteo wind attribution

Wind data is provided by the
[Open-Meteo Forecast API](https://open-meteo.com/en/docs). The fetcher does
not pin a specific forecast model; the API's default model selection is used.

Preserve Open-Meteo attribution and check the provider's current
[terms](https://open-meteo.com/en/terms) for the intended deployment and use.
This live federation does not retain an immutable response or provider
model-run identifier.
