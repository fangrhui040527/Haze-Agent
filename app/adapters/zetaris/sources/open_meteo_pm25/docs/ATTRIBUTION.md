# Open-Meteo PM2.5 attribution

PM2.5 data is provided by the
[Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api).
The API's air-quality forecasts use the Copernicus Atmosphere Monitoring
Service (CAMS) models; see
[CAMS](https://atmosphere.copernicus.eu/).

Open-Meteo documents attribution under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Preserve the
provider and model attribution when redistributing query results. Check the
provider's current terms for the intended deployment and use.

The API returns modeled values, not ground-station observations. The live
federation does not retain an immutable response or a provider-issued model
run identifier.
