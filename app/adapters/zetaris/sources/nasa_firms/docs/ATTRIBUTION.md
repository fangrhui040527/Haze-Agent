# NASA FIRMS Data Attribution

Data provided by the [NASA FIRMS (Fire Information for Resource Management System)](https://firms.modaps.eosdis.nasa.gov/).

- **Sensor**: VIIRS (Visible Infrared Imaging Radiometer Suite) aboard the Suomi NPP and NOAA-20 satellites.
- **Provider**: Land, Atmosphere Near real-time Capability for EOS (LANCE), NASA Goddard Space Flight Center.
- **Citation**: We acknowledge the use of data and/or imagery from LANCE FIRMS operated by NASA's Earth Science Data and Information System (ESDIS) with funding provided by NASA/HQ.
- **Terms**: Open access public domain under NASA Data Rights Policy. A free NASA Earthdata account Map Key is required for API access.
