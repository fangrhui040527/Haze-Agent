# Windy Data Attribution

Weather and air-quality forecast data provided by
[Windy.com](https://www.windy.com/) through the
[Windy Point Forecast API](https://api.windy.com/point-forecast/docs).

- **Attribution**: Any application or publication using this data must credit
  Windy.com.
- **Models**: The `gfs` layer is NOAA GFS; the `cams` layer is the Copernicus
  Atmosphere Monitoring Service global air-quality model.
- **Terms**: <https://api.windy.com/terms>
- **License**: Free **Testing** keys are for development only and return
  shuffled, modified data. Production use requires a **Professional** license
  (990 EUR/year).
