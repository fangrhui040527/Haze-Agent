# 2b. Explain how the USL helps the work

## Answer

The Environmental USL can help HazeOps investigate an episode by querying
air-quality, fire, and weather data with shared location tables. This makes it
easier to build a timeline for a selected place and period without repeating
the same source connections and location matching.

## Project benefit and time savings

For repeated investigations, shared tables and queries can reduce setup and
data preparation. I expect this to save time, but no measured time saving is
available yet. The [coverage guide](../../app/adapters/zetaris/usl/env_usl/docs/DATA_COVERAFES.md)
describes the sources and refresh schedule. See
[criterion 1c](1c-usl-and-data-quality.md) for example USL queries.
